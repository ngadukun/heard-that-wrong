## The line

Sorry, I heard order twelve pizzas — you said water the plants. The pizzas are already on their way. My bad.

## Run it

```sh
python3 main.py
```

Running it prints the apology and writes it to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
